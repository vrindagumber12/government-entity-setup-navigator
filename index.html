About

Government Entity Setup Navigator

An AI-enabled decision-support prototype for defining, designing, establishing and reviewing public organisations through structured evidence, MECE assessment, explicit dependencies and human decision gates.

What the MVP demonstrates

Jurisdiction-aware or anonymous setup
Country/state/city localisation or privacy-preserving jurisdiction-neutral mode
Evidence source configuration
Uploaded documents, online research or combined mode
12-component MECE assessment
4 pillars with one primary home for each issue
Design options and challenge function
Function-before-form logic
Dependency-aware setup roadmap
Critical path rather than checklist completion
Decision memory
Evidence, assumptions, rationale and review triggers

Production features not connected in this MVP

A production version would add secure authentication, encrypted document storage, real document parsing/RAG, live official-source web research, model orchestration, permissions, audit logs, multi-user approvals and server-side data persistence. The prototype intentionally uses local browser state only.

Scope boundary

The system structures evidence, options, dependencies and risks. It does not issue legal opinions, approve expenditure or appointments, or make the final decision to create or launch a public organisation.

MVP · All example entity names, findings, percentages and setup actions are illustrative. Do not use this prototype as legal, financial or operational approval.
